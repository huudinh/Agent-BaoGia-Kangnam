Lấy file PDF trên ChatGPT

Sandbox của ChatGPT không có Chrome nên không dựng thẳng ra PDF được. Nhưng file HTML do tool dựng tự đứng một mình (logo nhúng sẵn), mở bằng trình duyệt rồi in ra là khớp y hệt.

  1. Upload một file duy nhất tools/baogia-1file.py (156 KB) vào Knowledge — gói sẵn tool render, cổng pháp lý, hai template, bảng giá, danh sách bác sĩ và logo. Không cần ZIP repo.
  2. Chạy python baogia-1file.py du-lieu.json --chi-html — trả về trước bước tìm Chrome, ba cổng chặn vẫn chạy đủ.
  3. Mở file HTML → Ctrl+P → Lề: Không + bật Đồ hoạ nền → Save as PDF.

Tải riêng file đó: baogia-1file.py — nó tự bung ra thư mục tạm rồi gọi đúng render_baogia.py của repo, không chép lại logic nên không lệch bản gốc.

Hai thiết lập in ở bước 3 là bắt buộc: thiếu Lề: Không thì nội dung tràn thành 4–5 trang; thiếu Đồ hoạ nền thì mất hết khối navy — dải tổng chi phí và khối CTA thành trắng trơn.

⛔ Ảnh JPG gửi Zalo không dựng được ở ChatGPT — ảnh cần Chrome chụp. Máy nào cũng có Chrome sẵn, nên cách nhanh nhất là cài thêm Python rồi chạy tool thẳng trên máy.

Bản ngắn là bản đánh đổi. Nó đã cắt bảng chân dung khách, bảng giọng theo nhóm và nhiều luật chi tiết — và trông vào tri thức để bù.

Không nạp đủ file thì agent biết phải chặn gì nhưng không biết viết thế nào, và nó sẽ bắt đầu đoán ở đúng hai chỗ nguy hiểm nhất: giá và pháp lý.

Nửa tay — tool render

  
Cần Python 3.9+ và Chrome hoặc Edge.
    Pillow là tuỳ chọn — không có thì ảnh ra PNG, vẫn gửi được.

  
python -m pip install pillow        # tuỳ chọn

mkdir out\MAU
copy template\du-lieu.mau.json out\MAU\du-lieu.json
python tools\render_baogia.py out\MAU\du-lieu.json

  
Kết quả đúng phải là:

  
  cổng dữ liệu  : PASS
  cổng bảng giá : PASS
  => PDF    : out\MAU\BG-2026-1021-01.pdf  (4 trang)
  => ảnh 1..5 : out\MAU\BG-2026-1021-01-0X.jpg

  
Chrome ở chỗ khác thường → đặt biến môi trường KN_CHROME trỏ tới
    chrome.exe. Không có Chrome → chạy --chi-html rồi mở file HTML,
    Ctrl+P → Save as PDF.
